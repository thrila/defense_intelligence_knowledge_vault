# Defense, Intelligence & Industrial Tech Knowledge Vault

This repository is a structured Markdown knowledge vault mapping companies, technologies, contracts, math, and engineering domains across the defense, intelligence, and industrial technology ecosystem.

It is designed for **analysis**, **cross-linking**, and **systems-level understanding**, not news aggregation or speculation.

The vault is Obsidian-compatible but remains plain Markdown and tool-agnostic.

---

## What This Is

- A graph-style knowledge base built from **publicly verifiable information**
- One Markdown file per:
  - Company
  - Technology
  - Contract / program
  - Math or engineering method
  - Hardware / chip platform (when public)
- Heavy internal linking to expose **relationships, dependencies, and patterns**
- Written with an engineering / systems perspective (not marketing)

---

## What This Is NOT

- ❌ No classified information  
- ❌ No speculation presented as fact  
- ❌ No invented contracts, customers, chip designs, or internal stacks  
- ❌ No instructions for wrongdoing or exploitation  

If something is unclear or not publicly documented, it is either:
- explicitly marked as **Unverified / Needs Citation**, or  
- omitted entirely
