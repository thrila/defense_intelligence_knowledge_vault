# Software Engineering

Software engineering is the systematic application of engineering approaches to the development, operation, and maintenance of software. [source](https://en.wikipedia.org/wiki/Software_engineering)

Where it shows up in these industries:
- Building mission systems, analytics platforms, and embedded control software. [source](https://en.wikipedia.org/wiki/Software_engineering)

Typical outputs:
- Operational software platforms, embedded systems, and secure services. [source](https://en.wikipedia.org/wiki/Software_engineering)
