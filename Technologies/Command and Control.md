# Command and Control

Command and control (C2) is the exercise of authority and direction by designated commanders over assigned forces to accomplish missions. [source](https://en.wikipedia.org/wiki/Command_and_control)

Typical use in defense/industry:
- Coordinating sensors, decision support, and operational units across networks. [source](https://en.wikipedia.org/wiki/Command_and_control)

Key subcomponents:
- Situational awareness, communications, decision support, and tasking. [source](https://en.wikipedia.org/wiki/Command_and_control)

Links to companies using it:
- [[Companies/Anduril Industries]] provides C2 software platforms for autonomous and sensor networks. [source](https://en.wikipedia.org/wiki/Anduril_Industries)
- [[Companies/Lockheed Martin]] develops C2 systems integrated with air and missile defense programs. [source](https://en.wikipedia.org/wiki/Lockheed_Martin)
