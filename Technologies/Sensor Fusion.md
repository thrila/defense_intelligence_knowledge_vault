# Sensor Fusion

Sensor fusion combines data from multiple sensors to produce more accurate, consistent, and useful information than individual sensors alone. [source](https://en.wikipedia.org/wiki/Sensor_fusion)

Typical use in defense/industry:
- Fusing radar, EO/IR, and communications data for target tracking and situational awareness. [source](https://en.wikipedia.org/wiki/Sensor_fusion)

Key subcomponents:
- Data association, state estimation, and track management. [source](https://en.wikipedia.org/wiki/Sensor_fusion)

Links to companies using it:
- [[Companies/Lockheed Martin]] integrates multisensor data in advanced aircraft and defense systems. [source](https://en.wikipedia.org/wiki/Lockheed_Martin)
- [[Companies/RTX Corporation]] integrates sensors for air and missile defense. [source](https://en.wikipedia.org/wiki/RTX_Corporation)
