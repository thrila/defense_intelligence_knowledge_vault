# Data Integration

Data integration is the process of combining data from different sources into a unified view to enable consistent analysis and operations across systems. [source](https://en.wikipedia.org/wiki/Data_integration)

Typical use in defense/industry:
- Normalize and fuse operational, sensor, and logistics data to support mission planning and decision support. [source](https://en.wikipedia.org/wiki/Data_integration)

Key subcomponents:
- Extract-transform-load (ETL) or ELT pipelines, schema mapping, data quality, and metadata management. [source](https://en.wikipedia.org/wiki/Data_integration)

Links to companies using it:
- [[Companies/Palantir Technologies]] integrates heterogeneous data to build operational views for analysts and operators. [source](https://en.wikipedia.org/wiki/Palantir_Technologies)
