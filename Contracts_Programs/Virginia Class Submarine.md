# Virginia Class Submarine

The Virginia class is a class of nuclear-powered cruise missile submarines in service with the United States Navy. [source](https://en.wikipedia.org/wiki/Virginia-class_submarine)

Parties involved:
- Prime contractors: [[Companies/General Dynamics]] and Huntington Ingalls Industries. [source](https://en.wikipedia.org/wiki/Virginia-class_submarine)

Timeline:
- Construction began in the late 1990s with ongoing production. [source](https://en.wikipedia.org/wiki/Virginia-class_submarine)

Deliverables:
- Nuclear-powered attack submarines with multiple block variants. [source](https://en.wikipedia.org/wiki/Virginia-class_submarine)
