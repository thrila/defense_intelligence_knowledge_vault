# Type 26 Frigate

The Type 26 frigate (Global Combat Ship) is a class of anti-submarine warfare frigates for the Royal Navy. [source](https://en.wikipedia.org/wiki/Type_26_frigate)

Parties involved:
- Prime contractor: [[Companies/BAE Systems]]. [source](https://en.wikipedia.org/wiki/Type_26_frigate)

Timeline:
- The program was initiated in the 2010s with ongoing construction and variants for export customers. [source](https://en.wikipedia.org/wiki/Type_26_frigate)

Deliverables:
- Frigate variants for the UK and international customers. [source](https://en.wikipedia.org/wiki/Type_26_frigate)
